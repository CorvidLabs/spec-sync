# Context

SpecSync 4.x validates canonical module specifications but does not provide a durable feature/change lifecycle. Version 5.0 adds an opt-in SDD policy, portable workspaces, approvals, verification evidence, adoption, and agent-native JSON projections while preserving the existing module maturity lifecycle.
