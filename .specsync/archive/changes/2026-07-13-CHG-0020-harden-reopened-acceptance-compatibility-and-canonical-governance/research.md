# Research

The compatibility helper already recognizes both stable and transitional definition encodings. Successor history already proves accepted state from Git, but its predicate did not distinguish semantic from no-spec workspaces. Effective-contract validation uses one record set both to select modules and replay pending deltas, so reopened canonical-applied records need module selection without delta replay.
