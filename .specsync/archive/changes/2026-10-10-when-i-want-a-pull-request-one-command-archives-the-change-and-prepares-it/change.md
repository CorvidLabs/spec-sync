# When I want a pull request, one command archives the change and prepares it

## Intent

When I want a pull request, one command archives the change and prepares it

## Affected Canonical Specs

- `cmd_change`
- `cli_args`

## Acceptance Criteria

- When I want a pull request, one command archives the change and prepares the pull request.
- If the pull request is already open, that command leaves that pull request in place.
- That command does not merge the pull request.
