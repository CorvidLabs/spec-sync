# Design

Keep each correction inside the existing lifecycle helpers. Historical reconstruction filters the current acknowledgement set by the predecessor sequence. Canonical module coverage compares normalized paths against the two paths returned by `canonical_module_paths`. Protected-path matching includes both current and legacy registry authorities. Recursive verification rejects direct SpecSync programs and Cargo invocations that explicitly or implicitly resolve to the SpecSync binary. Cargo package values remain dependency-free and are parsed only inside the `[package]` table.
