## Criteria

- **INSTALL-1**  The prebuilt Linux download starts on the oldest Linux the install guide says it supports, not only on the newest.
  - **INSTALL-1.a**  The install guide names that oldest Linux plainly.
  - **INSTALL-1.b**  When my Linux is older than that, the guide tells me which download still works.
  - **INSTALL-1.c**  A release whose Linux download would not start on that oldest Linux is stopped before anyone can download it.
